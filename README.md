# sea-api
它是一台机器上常驻的模型额度路由器：把本机 WorkBuddy 已登录的额度、十家账号渠道，以及你自加的 OpenAI 兼容端点，汇成一个本地地址，供 Claude Code、Codex、opencode 等客户端使用。  接入走五步向导：选类型、填凭据、勾模型、确认能力、真实探活。对外三套协议入口（/v1、/anthropic、/openai）共用一份模型清单；路由按优先级链降级，只有能力等价才换下一跳，一条来源可挂多条链。  自带账本、日志、体检与用量热力图，支持额度查询与签到。Key 分默认与具名，管理写操作只收回环；局域网共享默认关闭，开启须确认风险，访客只能读。单 exe，前端与迁移全内置，分开源版与加密版。
